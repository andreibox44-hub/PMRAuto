# PMRAuto

## Что это за сайт

PMRAuto — площадка объявлений о продаже транспорта для Приднестровья (ПМР) и Молдовы.
Пользователи смотрят каталог, ищут машины по фильтрам, регистрируются, размещают свои
объявления и переписываются с продавцами.

## На чём сделан

- **Один файл `index.html`** (~270 КБ, ~5000 строк): разметка, CSS и JavaScript внутри.
  Рядом лежат иконки (`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`) и картинка
  превью для соцсетей `og-image.png` (1200×630).
- **Важно:** первая строка файла сразу закрывает `<head>`. Метатеги (title, description,
  Open Graph, иконки) стоят внутри неё перед `</head>` — новые теги для `<head>` добавлять туда.
- **Чистый HTML + CSS + JavaScript** без фреймворков и сборщиков. Своего сервера нет.
- **Бэкенд — Supabase** (проект `pguqsuamvakmoejnqhze`, https://pguqsuamvakmoejnqhze.supabase.co).
  Библиотека `supabase-js@2.58.0` подключена с jsdelivr с `integrity`. В начале скрипта —
  `SUPABASE_URL` и публичный ключ `SUPABASE_KEY` (publishable, его можно держать в коде;
  секретный ключ в код не вставлять). Там лежат пользователи (Supabase Auth, вход по e-mail
  и паролю), профили, объявления, чаты, сообщения и фото (Storage, папка `photos`).
- **Схема базы — `supabase/schema.sql`**: таблицы `profiles`, `listings`, `chats`, `messages`,
  правила доступа (RLS), функции `username_taken`, `my_chats`, `mark_chat_read`,
  `delete_my_account`, Storage-папка `photos`. Скрипт можно запускать повторно
  (Supabase → SQL Editor). **Любое изменение схемы — сначала в этот файл, потом запустить.**
- Телефон из профиля — личный: хранится в `user_metadata.phone` пользователя, а не в
  общей таблице `profiles` (её видят все).
- В `localStorage` остались только язык, избранное, сравнение и время последнего вопроса
  (`const KEYS`), плюс сессия Supabase. Ключи старой версии (`OLD_KEYS`) удаляются при запуске.
- **Фото примеров** лежат в папке `img/` (JPEG), в `SEED` и `HERO_PHOTO` указаны путями
  `img/...`. Функция `photoSrc()` берёт картинку из `window.EMBEDDED_PHOTOS`, если её туда
  встроили, иначе — по пути. Пути относительные: это работает, потому что роутер меняет
  только часть адреса после `#`, а путь страницы остаётся прежним. Если роутер начнёт
  менять сам путь (без `#`) — пути к картинкам надо поправить.
- **Шрифт** Onest из Google Fonts.
- **Форма «Задать вопрос»** отправляет письма через сервис Web3Forms
  (`WEB3FORMS_ACCESS_KEY` в начале скрипта).
- Цвета заданы CSS-переменными в `:root`, есть тёмная тема (`prefers-color-scheme: dark`).

### Устройство кода

- Роутер: `go(name, param)` и `router()`. У каждой страницы свой адрес через решётку
  (работает на GitHub Pages без настроек): `#/`, `#/search?brand=BMW&…` (только фильтры,
  отличные от `DEFAULT_FILTERS`), `#/car/<id>`, `#/sell`, `#/sell/<id>` (редактирование),
  `#/account/<вкладка>`, `#/account/messages/<id чата>`, `#/page/<id>`, `#/favorites`,
  `#/compare`. Перевод туда-обратно — `routeToHash()` / `hashToRoute()`, запись в историю —
  `setHistory()`. Адрес — источник правды: при загрузке (`boot`) и на «Назад» (`popstate`)
  страница берётся из него. Ссылкам `[data-go]` настоящий `href` подставляется при наведении
  (`linkHash`), поэтому работают «Открыть в новой вкладке» и Ctrl+клик.
  Маршруты: `home`, `search`, `car`, `sell`, `account`, `page`, `favorites`, `compare`
  (`my` — старый адрес, ведёт на `#/account/listings`).
- Служебные адреса Supabase из писем (`#access_token=…`, `#error=…`) — не маршруты:
  открывается главная, адрес приводится к `#/`. Ссылку с ошибкой убираем ещё до запуска
  Supabase, иначе он выходит из аккаунта.
- Страницы только для вошедших (`requireLogin()`) после входа открывают ту страницу, куда шли.
- Если объявления нет в памяти (свежая ссылка), `refetchMissing()` один раз перезагружает
  данные с сервера, и только потом показывается «не найдено».
- Каждая страница рисуется функцией `view*()` (`viewHome`, `viewSearch`, `viewDetail`,
  `viewSell`, `viewAccount`, `viewPage`, `viewFavorites`, `viewCompare`) в `<main id="app">`.
- Тексты интерфейса — в объекте `I18N` (`ru`/`en`), вывод через `t('ключ')`, склонения — `plural()`.
  **Любой новый текст нужно добавлять в оба языка.**
- **Справочник марок и моделей — `catalog.js`** (`window.VEHICLE_CATALOG`, подключён перед
  основным скриптом): для `car`, `moto`, `truck`, `van` — `popular` (популярные марки по
  порядку, первые 12 — плитки на главной) и `models` (марка → модели примерно с 2000 года).
  Модели — семействами (BMW «3 Series», Mercedes «C-Class»); `resolveModel()` относит к ним
  «320d», «C 200 4MATIC» и т. п. В списках марок сверху «Популярные марки», потом «Все марки»,
  в конце «Другая» (`OTHER`) — при ней появляется поле для ручного ввода. Марки и модели
  сортируются `byName` (по алфавиту, числа по значению). Своя марка/модель из объявлений
  попадает в списки поиска автоматически. Форма подачи: `setSellBrandModel()`,
  `updateSellModels()`, `readSellBrandModel()`; поиск: `bindSearchForm()`, `searchOther`,
  `resetFilters()`. Русские названия и другие написания марок — `BRAND_RU`, `BRAND_ALIASES`.
- Характеристики (топливо, КПП, кузов) хранятся кодами (`petrol`, `automatic`, `sedan`…),
  старые русские значения переводятся через `LEGACY_VALUES`.
- **Данные с сервера** загружаются при запуске (`boot()` → `loadData()`) и лежат в памяти
  в объекте `db` (`db.listings`, `db.users`, `db.me`), поэтому страницы рисуются без ожидания.
  `refreshData()` обновляет их не чаще раза в 30 с при переходах. Внутри кода пользователи —
  это **логины** (`owner`, `buyer`, `seller`); id из базы нужны только для запросов
  (`listing.ownerId`, `db.me.id`, `nameOf(id)`).
- Чаты — через `chatApi` (запросы к Supabase), новые сообщения приходят сразу через
  Supabase Realtime (`subscribeMessages`).
- Примеры объявлений — `SEED` в коде (не в базе), `buildExamples()` при запуске; написать
  по ним нельзя.
- Комментарии в коде — на русском.

## Что уже есть

- **Главная**: шапка с логотипом, герой-баннер, быстрый поиск, плитки марок, свежие объявления.
- **Каталог и поиск**: фильтры по виду транспорта (авто, мото, грузовики, фургоны), марке,
  модели, году, цене, пробегу, городу (ПМР и Молдова), топливу, КПП, текстовый поиск;
  сортировка (новые, цена, год, пробег).
- **Карточка объявления**: галерея фото, характеристики, блок цены, контакты продавца,
  кнопка «Написать продавцу».
- **Регистрация и вход** (Supabase Auth): регистрация — логин + e-mail + пароль, вход —
  e-mail + пароль, «Забыли пароль?» (письмо со ссылкой, потом окно «Новый пароль»).
  Подтверждение e-mail в Supabase **выключено** (встроенная почта Supabase шлёт всего
  несколько писем в час); код умеет работать и с включённым.
- **Личный кабинет** с вкладками: профиль (аватар, имя, город, телефон, e-mail/Telegram,
  процент заполненности), сообщения, мои объявления, безопасность (смена пароля,
  удаление аккаунта вместе с объявлениями, фото и чатами).
- **Подача объявления**: форма с проверкой полей, до 10 фото (до 20 МБ, уменьшаются до
  1280 px и загружаются в Storage), редактирование и удаление своих объявлений.
  Редактирование — та же форма: маршрут `sell` с id объявления (`viewSell(id)`, `editingId`),
  кнопки «Редактировать» на странице объявления и «Изменить» в «Моих объявлениях».
  При сохранении загружаются только новые фото, убранные удаляются из Storage.
- **Чаты** между покупателем и продавцом, счётчик непрочитанных, сообщения приходят сразу.
- **Избранное и сравнение**: сердечко и «весы» на карточках и на странице объявления,
  ссылки со счётчиками в шапке («Сравнение» видно, только когда в нём что-то есть).
  Страница «Сравнение» — таблица до 4 объявлений (`COMPARE_MAX`), лучшие цена, год, пробег
  и мощность подсвечены зелёным. Работает без входа; списки id — в `am_favorites`
  и `am_compare` (общие для браузера, не для аккаунта). Код — блок «Избранное и сравнение».
- **Два языка**: русский и английский, переключатель в шапке, автоопределение по браузеру.
- **Подвал**: страницы «О нас», «Контакты», политика конфиденциальности, условия,
  Impressum, cookies. Иконок соцсетей нет (убраны, пока нет профилей PMRAuto).
- **Кнопка «Задать вопрос»**: форма с темами (вопрос, проблема, идея) и антиспамом
  (скрытое поле, минимум 3 с на заполнение, пауза 60 с, не больше 2 ссылок).
- Тёмная тема, адаптивная вёрстка под телефон, всплывающие уведомления (toast),
  синхронизация между вкладками браузера.
