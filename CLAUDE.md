# PMRAuto

## Что это за сайт

PMRAuto — площадка объявлений о продаже транспорта для Приднестровья (ПМР) и Молдовы.
Пользователи смотрят каталог, ищут машины по фильтрам, регистрируются, размещают свои
объявления и переписываются с продавцами.

## На чём сделан

- **Один файл `index.html`** (~2 МБ, ~4200 строк): разметка, CSS и JavaScript внутри.
- **Чистый HTML + CSS + JavaScript** без фреймворков, сборщиков и сервера.
- **Данные хранятся в `localStorage` браузера** (ключи с префиксом `am_`, см. `const KEYS`).
  Сервера и базы данных нет: у каждого посетителя свои объявления, пользователи и сообщения.
- **Фото примеров** встроены в файл как base64 (`window.EMBEDDED_PHOTOS`) — поэтому файл тяжёлый.
- **Шрифт** Onest из Google Fonts.
- **Форма «Задать вопрос»** отправляет письма через сервис Web3Forms
  (`WEB3FORMS_ACCESS_KEY` в начале скрипта).
- Цвета заданы CSS-переменными в `:root`, есть тёмная тема (`prefers-color-scheme: dark`).

### Устройство кода

- Роутер: `go(name, param)` и `router()`, история браузера через `history.pushState`.
  Маршруты: `home`, `search`, `car`, `sell`, `account`, `page` (`my` — старый адрес).
- Каждая страница рисуется функцией `view*()` (`viewHome`, `viewSearch`, `viewDetail`,
  `viewSell`, `viewAccount`, `viewPage`) в `<main id="app">`.
- Тексты интерфейса — в объекте `I18N` (`ru`/`en`), вывод через `t('ключ')`, склонения — `plural()`.
  **Любой новый текст нужно добавлять в оба языка.**
- Характеристики (топливо, КПП, кузов) хранятся кодами (`petrol`, `automatic`, `sedan`…),
  старые русские значения переводятся через `LEGACY_VALUES`.
- Примеры объявлений — `SEED`, загружаются один раз (`seedIfNeeded`, флаг `am_seeded_v5`).
- Комментарии в коде — на русском.

## Что уже есть

- **Главная**: шапка с логотипом, герой-баннер, быстрый поиск, плитки марок, свежие объявления.
- **Каталог и поиск**: фильтры по виду транспорта (авто, мото, грузовики, фургоны), марке,
  модели, году, цене, пробегу, городу (ПМР и Молдова), топливу, КПП, текстовый поиск;
  сортировка (новые, цена, год, пробег).
- **Карточка объявления**: галерея фото, характеристики, блок цены, контакты продавца,
  кнопка «Написать продавцу».
- **Регистрация и вход**: логин/пароль, пароль хранится как SHA-256 с солью (учебная схема,
  всё в браузере).
- **Личный кабинет** с вкладками: профиль (аватар, имя, город, телефон, e-mail/Telegram,
  процент заполненности), сообщения, мои объявления, безопасность.
- **Подача объявления**: форма с проверкой полей, до 10 фото (до 20 МБ, с уменьшением),
  редактирование и удаление своих объявлений.
- **Чаты** между покупателем и продавцом, счётчик непрочитанных.
- **Два языка**: русский и английский, переключатель в шапке, автоопределение по браузеру.
- **Подвал**: страницы «О нас», «Контакты», политика конфиденциальности, условия,
  Impressum, cookies; ссылки на соцсети (пока на главные страницы платформ).
- **Кнопка «Задать вопрос»**: форма с темами (вопрос, проблема, идея) и антиспамом
  (скрытое поле, минимум 3 с на заполнение, пауза 60 с, не больше 2 ссылок).
- Тёмная тема, адаптивная вёрстка под телефон, всплывающие уведомления (toast),
  синхронизация между вкладками браузера, контроль заполненности хранилища.
